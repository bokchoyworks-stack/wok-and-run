WOK AND RUN

隐私政策

本政策说明 Wok and Run 如何处理信息。

生效日期：2026年9月21日 · 开发者：Hiroki Murai / Bokchoy Works

概要：无需注册账户。游戏进度保存在设备本地。购买完整游戏升级前，应用使用面向儿童的非个性化 Google AdMob。

1. 应用处理的信息

Wok and Run 无需注册账户。开发者不会直接收集姓名、电子邮件地址、精确位置、通讯录、照片或游戏内容。关卡进度、语言、声音等设置仅保存在设备本地。

2. 广告与 Google AdMob

购买完整游戏升级前，应用使用 Google AdMob。广告只会在失误五次后的15秒继续游戏画面中显示。应用将广告设置为面向儿童处理，将广告内容限制为普通级，并停用个性化广告。Google Mobile Ads 可能为广告投放、防欺诈、分析及 SDK 运行自动处理 IP 地址（可能用于估算大致位置）、设备标识符、广告数据、产品互动、崩溃日志和性能数据。本应用不会请求 App Tracking Transparency 权限，开发者也不会使用这些信息建立由开发者控制的用户档案。

3. 应用内购买

“完整游戏升级”包含解锁第4至20关和移除广告，是由 Apple 通过 StoreKit 处理的一次性购买。开发者只能获取购买权益状态，不会获取银行卡信息。

4. 儿童隐私

本应用已设置为面向儿童处理。我们不会要求儿童提交个人信息。购买和外部链接设有家长验证。

5. 隐私选择

在适用地区，可从游戏设置画面打开隐私选项，也可使用 iOS 的隐私设置。购买“完整游戏升级”后，应用内不会再显示 AdMob 横幅广告。

6. 保存与共享

开发者不运营用于保存用户档案或游戏记录的服务器。Google 和 Apple 会依照各自政策保存及处理信息。法律要求或为保护用户和服务时，信息可能被披露。

7. 跨境处理

Google 和 Apple 可能依照各自保障措施及适用法律，在用户居住地以外的国家或地区处理信息。

8. 变更与联系

应用或适用要求发生变化时，我们可能更新本政策。最新版本和生效日期将持续发布在本页。如有隐私问题，请通过支持页面联系我们。
